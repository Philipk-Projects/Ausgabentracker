# AusgabenTracker

Eine einfache Webseite, mit der du tägliche Ausgaben erfassen kannst. Die Daten werden direkt im Browser gespeichert und bleiben auch nach dem Neuladen der Seite erhalten.

## Funktionen

- Ausgaben mit Beschreibung, Betrag und Kategorie hinzufügen
- Gesamtausgaben automatisch berechnen
- Einzelne oder alle Einträge löschen
- Funktioniert ohne Anmeldung und ohne Installation

## Starten

1. Lade die Dateien herunter oder klone dieses Repository.
2. Öffne `index.html` in einem Browser.

## Auf dem Handy nutzen

Wenn die Seite über GitHub Pages veröffentlicht ist, kann sie über einen Link geöffnet und wie eine App installiert werden:

- iPhone: Link in Safari öffnen, auf **Teilen** tippen und **Zum Home-Bildschirm** wählen.
- Android: Link in Chrome öffnen und **App installieren** oder **Zum Startbildschirm hinzufügen** wählen.

## Verwendete Technologien

HTML, CSS und JavaScript
